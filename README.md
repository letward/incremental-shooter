# Incremental Shooter

A simple, easy-to-understand first-person incremental shooter built with **Godot 4.7**.

## Gameplay
- WASD move, mouse look, LMB shoot, R reload, Space jump, Shift sprint.
- Kill enemies to earn money. Spend it on upgrades (damage, fire rate, health, speed, magazine, reload, armor, lifesteal).
- Waves of enemies with scaling difficulty. Three enemy types: Grunt, Runner, Brute.

## Controls
| Key | Action |
|-----|--------|
| W/A/S/D | Move |
| Mouse | Look |
| LMB | Shoot |
| R | Reload |
| Space | Jump |
| Shift | Sprint |
| Tab | Upgrades |
| Esc | Toggle cursor |

## Run
Open `project.godot` in Godot 4.7+ and press Play.
